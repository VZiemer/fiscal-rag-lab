Do not submit CPF/CNPJ identifiers, NF-e XML, personal data or secrets. The application does not persist queries or responses. Embeddings use a local lexical control, without sending data to an LLM or external provider.

Application logs contain only a random ID, categorized route, status and duration; they exclude query text, IP addresses, bodies, headers and credentials. CloudWatch retains these logs for 7 days. Connection addresses may be used in memory for quotas and are discarded during window cleanup, without application storage.

CloudFront and API Gateway process requests and network addresses for delivery and protection. This deployment does not enable access logs; AWS services may produce metrics and operational records under their own policies. The client platform applies its own privacy policies.

The public corpus consists of ten editorial paraphrases of Receita Federal pages about NCM/Classif, with source and checksum. It contains neither private taxpayer data nor a complete official code table. Unknown validity dates remain unknown.

Experimental service without user authentication and with request limits. It is unsuitable for confidential data. This policy describes the technical deployment and does not claim comprehensive legal compliance.
